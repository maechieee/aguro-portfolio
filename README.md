# Jeremae Aguro — Portfolio

Personal portfolio of Jeremae Aguro, an aspiring full-stack web developer and BSIT student
based in Roxas City, Capiz, Philippines.

Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
npm run start
```

## Updating content

- `data/profile.ts` — name, title, summary, email, GitHub, LinkedIn, photo
- `data/skills.ts` — skills matrix
- `data/projects.ts` — project case studies (screenshots go in `public/<project-id>/`)
- `data/experience.ts` — education and experience
- `data/certifications.ts` — certifications
- `data/documents.ts` + `public/documents/` — résumé, cover letter, developer guide PDFs

Set `NEXT_PUBLIC_SITE_URL` to the deployed URL for correct share-preview metadata.
